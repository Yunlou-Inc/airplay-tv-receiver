# 安全编码规范

## 输入与协议

- 所有网络字段设置显式最大长度；先校验再分配，检查加减乘和类型转换溢出。
- 解析器拒绝重复冲突字段、非法编码、额外尾随数据和未知关键能力；禁止“尽量解析”。
- 状态机显式枚举允许迁移；乱序、重复、跨会话消息安全失败。
- 设置读取、握手、空闲和关闭超时；限制并发连接、请求速率、缓冲及媒体尺寸。

## 内存、并发与资源

- 新代码优先内存安全语言；不安全代码最小化、封装并附安全论证与测试。
- 资源使用作用域所有权/自动释放；覆盖断连、取消、部分读取和异常路径。
- 共享状态避免数据竞争；锁顺序固定，回调不得持锁调用不可信组件。
- 解码进程最小权限且不访问长期密钥、任意文件或网络。

## 密码学与秘密

- 仅使用经维护库和协议规定且经审查的原语；禁止自制密码学、固定随机数、静默降级。
- 随机数来自操作系统密码学随机源；比较认证标签使用常数时间接口。
- 密钥按会话隔离、限制生命周期并尽力清零；长期秘密进入平台安全存储。
- 测试密钥只能用于测试，明确标识且 Release 构建门禁检查其不存在。

## 日志与隐私

允许记录版本、状态、计数、泛化错误码；禁止记录密钥、令牌、配对码、完整设备标识、原始控制报文、媒体内容和未脱敏网络地址。生产日志默认最小化且有保留期限。

## 错误处理与供应链

- 外部错误统一、内部错误可追踪但脱敏；安全检查不得仅靠断言。
- 依赖锁定、校验来源并登记许可证；高风险依赖更新需回归和安全审核。
- 编译启用平台防护、静态分析和适用消毒器；警告不得无说明抑制。

## 评审清单

- [ ] 输入上限、超时、取消和资源预算已定义
- [ ] 授权发生在副作用之前，失败路径清理秘密
- [ ] 无敏感日志、硬编码秘密或测试后门
- [ ] 协议状态、并发、模糊和负面测试齐全
- [ ] 威胁模型、依赖清单和兼容状态同步更新
