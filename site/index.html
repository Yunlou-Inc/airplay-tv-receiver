装到电视上，iPhone / iPad 用系统自带的「屏幕镜像」就能把画面投上去。开源、无广告、不要账号。

三步开始投屏

1

手机和电视连同一个路由器

电视插网线、手机连这个路由器的 WiFi 也算同一网络。跨网段、开了 AP 隔离的路由器会让手机搜不到电视。

2

在 iPhone / iPad 上打开控制中心

从屏幕右上角向下滑。视频 App 里也可以直接点播放器上的 AirPlay 图标。

3

点「屏幕镜像」，选中这台电视

电视上「云楼投屏」里显示「等待设备连接」即表示服务已就绪，选中后会立刻出现画面。

安装说明

安装包在 GitHub Releases 里，点上面的「下载安装包」即到最新版页面，下载 YunlouAirPlayTV-<版本>-release.apk。

  • 用 U 盘装：U 盘格式化为 FAT32，APK 放根目录，插到电视上从文件管理器打开。
  • 先允许「未知来源应用」：设置 → 安全与隐私 → 未知来源应用 → 允许。
  • 电视剩余空间留 600 MB 以上。
  • 如果提示「应用未安装 / 更新不兼容」，先在「设置 → 应用」里卸载旧版本再装。

常见问题

电视上搜不到这台设备

按顺序排查：

  • 手机和电视是否在同一个路由器的同一个网段（手机用 4G/5G 流量时必然搜不到）。
  • 路由器是否开了「AP 隔离 / 客户端隔离」，开了就互相看不见，关掉即可。
  • App 里点过「启动」、状态显示「等待设备连接」了吗。
  • 部分电视的省电策略会杀掉后台服务，可在设置里允许「后台运行」。
安装时提示「解析包错误」

绝大多数是下载不完整。先核对文件大小和 SHA256（见下一条），确认完整再装。若大小一致仍报错，可能是电视系统版本低于 Android 6.0。

怎么确认下载的包没被篡改

Release 页面附有 .sha256 校验文件，内容应与本地计算结果一致：

# macOS / Linux
shasum -a 256 YunlouAirPlayTV-*-release.apk

# Windows PowerShell
Get-FileHash .\YunlouAirPlayTV-*-release.apk -Algorithm SHA256

App 内「设置 → 关于 → 签名指纹」显示的证书指纹，与 Release 说明里的证书 SHA-256 前 8 字节一致，说明是同一条发布流水线出的包。

投屏卡顿、画面糊

投屏走的是局域网，2.4G WiFi 带宽常常不够。电视尽量走网线，或让手机和电视都连 5G 频段。App 的「高级」里可以调 H.265、最大帧率等参数，默认值适合大多数情况。

有广告吗？会收集数据吗？

没有。App 不含账号体系、不上传数据、没有广告和统计 SDK，所有流量都在你家局域网内。源码全部公开，可自行审计或自行编译。
